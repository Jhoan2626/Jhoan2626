# Banner

Espacio reservado para una imagen de portada del perfil (hero).

**Recurso pendiente:** una imagen banner, sugerida en formato PNG o SVG, tamaño aproximado 1200×300px, acorde a la paleta oscura del README (`#0D1117` fondo, acentos `#00D4FF` / `#7C3AED`). Al proporcionarla, se referenciará desde la sección Hero del `README.md` principal.

Opcional: si se proveen dos versiones (clara/oscura), se puede usar `<picture>` con `prefers-color-scheme` para que GitHub muestre la versión correcta según el tema del visitante.
